# Frontend Application (React + Vite)

The UI layer for the CDI/EDI Engineering Design Platform.

## Features
- **Interactive Engineering Dashboard**: Real-time water desalination calculation and optimization.
- **Technology Modals & Visualizers**: 3D CAD Stack Viewer, Dynamic P&ID Diagrams, and Bill of Materials (BOM).
- **Equation Editor**: Live mathematical formula parsing, custom user equations, and PDF export.
- **Design Traceability**: Complete step-by-step formula and provenance inspection dialogs.

## Scripts
```bash
# Start local development server
npm run dev

# Build production bundle
npm run build

# Preview build
npm run preview
```
